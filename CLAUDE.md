# Portfolio Development Rules

## Tech Stack
- Framework: Next.js (App Router)
- Styling: Tailwind CSS
- Icons: Lucide React

## Development Guidelines
- Always prioritize a mobile-first responsive layout (smooth scaling from mobile viewports to ultra-wide desktop displays).
- Use semantic HTML tags.
- Adhere strictly to the `taste-skill` design directives (avoid generic cards, generic spacing, and boring typography combinations).
- Write clean, modular components inside `src/components/`.
